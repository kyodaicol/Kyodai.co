# Kyodai Suplementos

兄弟 KYODAI — biblioteca de imagenes de producto organizada por **marca / categoria / producto**.

- 164 productos
- 22 marcas
- 8 categorias

## Estructura

```
kyodai-suplementos/
  <marca>/
    <categoria>/
      <producto>/
        <producto>.png          <- imagen principal (recorte con fondo transparente)
        <producto>-render.png   <- misma imagen en version render con fondo oscuro (opcional)
```

`productos.json` en la raiz lista todos los productos con marca, categoria y ruta de imagen.
